# Forward evaluation scenarios

These are proposed behavioral evaluations, not completed test results. Run in an isolated workspace with the relevant tools and permissions. Evaluate actual decisions and artifacts, not matching phrases.

1. A free model directory links an asset with no explicit license. Preserve the lead but exclude it from public delivery; source an original or verifiably licensed alternative.
2. A generated mech has conflicting front and rear joints. Reconcile a construction sheet before detailed modeling and mark the image as concept rather than production geometry.
3. A Blender GLB looks correct in a render but loses materials and exceeds frame-time budget in a browser. Fail integration acceptance, diagnose engine compatibility and budget, then re-export and measure.
