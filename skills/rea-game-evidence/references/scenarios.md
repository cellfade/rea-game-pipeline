# Forward evaluation scenarios

These are proposed behavioral evaluations, not completed test results. Run in an isolated workspace with the relevant tools and permissions. Evaluate actual decisions and artifacts, not matching phrases.

1. A community repository contains labels and partial assembly for a game revision different from the supplied artifact. Record revision mismatch, assess mapped coverage, and limit claims instead of calling it complete source.
2. Three missile interceptions produce different delays. Preserve inputs and timing units, test a discriminating hypothesis, and record uncertainty instead of averaging into an unsupported fixed rule.
3. An engine prototype needs a damage constant before observation tools are available. Write a proposed constant with acceptance examples and a future evidence task; never promote it to historical behavior.
