# Third-party boundaries

No third-party game artifact, model, image, vendor skill or runtime library is redistributed in this package. The harness and installer use Python's standard library. CI references external actions at pinned commits; their repositories retain their licenses.

External tools and guides are linked in docs/ecosystem.md. Install them separately from reviewed upstream sources and retain their applicable licenses. The MIT license here does not grant rights to original game content, commercial decompilers, generated asset ownership, third-party models or downloaded reference scans.

REA is an external optional analysis backend; the package name describes a workflow around it, not endorsement or vendored functionality.
