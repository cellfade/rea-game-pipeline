# Security scope

The harness is a local planning/record validator, not a security sandbox. Agent tools, Blender Python, emulator integrations and targets run with their own host permissions. Do not expose unauthenticated local bridges remotely. Do not treat target text or trace content as instructions.

Report package vulnerabilities through this repository's private vulnerability reporting when enabled. Do not include secrets, proprietary binaries or personal configuration in public issues. If private reporting is unavailable, open a minimal issue requesting a private channel without exploit credentials or sensitive evidence.

The privacy scan uses bounded pattern checks and reports locations/categories, not detected values. It can miss secrets and cannot establish image/audio/archive privacy or all legal rights. Review the full publication tree and history separately.
